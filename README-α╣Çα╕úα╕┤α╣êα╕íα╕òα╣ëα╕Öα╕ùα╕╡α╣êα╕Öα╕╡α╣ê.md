# ชุดเริ่มต้นพัฒนาระบบ (Starter Kit)

ชุดนี้ใช้ในหลักสูตรการพัฒนาระบบดิจิทัลเพื่อการนิเทศ สพม.หนองคาย ทุกคนเริ่มจากจุดเดียวกัน

## ในชุดมีอะไรบ้าง
| ไฟล์ / โฟลเดอร์ | ใช้ทำอะไร |
|---|---|
| BLUEPRINT.md | แบบฟอร์ม Blueprint ของระบบ เติมให้ครบก่อนสั่ง AI สร้าง |
| AGENTS.md, CLAUDE.md | คำแนะนำที่ Codex และ Claude Code อ่านอัตโนมัติ (ให้อ่าน Blueprint ก่อนเสมอ) |
| apps-script/ | โค้ดระบบบันทึกข้อมูลด้วย Google Apps Script (วันที่ 1) |
| app/ | เว็บไซต์ Next.js ที่ดึงข้อมูลจาก Apps Script (วันที่ 2) |
| .env.example | ตัวอย่างการตั้งค่าค่าลับ |
| 0-check-ready.bat | ดับเบิลคลิกเพื่อตรวจว่าติดตั้งโปรแกรมครบ |
| 1-install-and-run.bat | ดับเบิลคลิกเพื่อติดตั้งและรันระบบในเครื่อง |

## ขั้นตอน
1. แตกไฟล์ zip ไปไว้ที่ C:\ ให้ได้โฟลเดอร์ C:\nithet-starter (ตรวจว่าไม่มีโฟลเดอร์ซ้อนกันสองชั้น) แล้วเปลี่ยนชื่อโฟลเดอร์เป็นชื่อระบบของตนเอง ภาษาอังกฤษตัวพิมพ์เล็ก ไม่มีช่องว่าง
2. ดับเบิลคลิก 0-check-ready.bat ทุกบรรทัดต้องขึ้นเลขรุ่น
3. เปิด VS Code → File → Open Folder → เลือกโฟลเดอร์นี้
4. เติม BLUEPRINT.md ให้ครบ (ใช้ผลจากตัวช่วยออกแบบระบบและใบงานที่ 1)
5. ตั้งค่าเชื่อมข้อมูล: คัดลอกไฟล์ .env.example เป็น .env.local แล้วใส่ลิงก์เว็บแอป Apps Script และรหัสลับ
6. ดับเบิลคลิก 1-install-and-run.bat แล้วเปิด http://localhost:3000
7. สั่งเอเจนต์ใน VS Code: “อ่าน BLUEPRINT.md แล้วปรับหน้าแรกให้เป็นหน้าแนะนำระบบตาม Blueprint”
8. ทดสอบ แล้วบันทึกด้วย Git และส่งขึ้น GitHub (ดูคู่มือคำสั่งที่ใช้ประจำ)

## ถ้าติดปัญหา
คัดลอกข้อความผิดพลาดทั้งหมด จับภาพหน้าจอ แล้วถามผู้ช่วยปัญญาประดิษฐ์ตามแบบ “ขอความช่วยเหลือเมื่อติดปัญหา” ในคู่มือ (คำสั่ง ข.8)
ห้ามส่งไฟล์ .env.local หรือรหัสลับให้ผู้ช่วยปัญญาประดิษฐ์
